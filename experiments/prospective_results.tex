\paragraph{Prospective laboratory pilot.} We froze 12 telecom tasks and one run per system before collecting new model outputs. The pilot completed 0 of 24 planned runs and 0 paired tasks, using 1 provider requests with \$0.0079 accounted expenditure under a \$4.00 cap. The systems were GPT-5.6-Luna and Claude Haiku 4.5, with the same Luna user simulator, randomized execution order, 40-step truncation and deterministic task verification. This is paired shadow execution in a laboratory, not a live-production A/B experiment. The small prespecified pilot is descriptive; it does not establish deployment superiority or real-user generalization.
