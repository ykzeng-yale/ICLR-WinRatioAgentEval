# Scoped arXiv successor experiment plan

September 19, 2026. The bounded v1 article is technically verified with existing evidence. Its caveats remain: synthetic operating characteristics, historical/ordinal trace replay, post-hoc coding running-mean inference and descriptive airline batches are not fresh production randomized evidence. No new experiment is retroactively required to make a claim already restricted to those scopes.

The author authorized continued open-weight work. Two concrete tasks now address the main remaining online-evaluation gap:

1. **Prospective monitored execution — [issue 11](https://github.com/ykzeng-yale/ICLR-WinRatioAgentEval/issues/11).** Already claimed by `iclr-winratioagentevals-60`, with exclusive new directories. Its first deliverable is an outcome-blind protocol/adapter freeze plus a small instrumentation pilot, not a favorable comparison. Root's [independent design guidance](../reviews/arxiv_live_design_guidance.md) requires paired AB/BA assignment, fixed enrollment indexing, valid partial-score bounds, simultaneous alpha allocation, defensible margins, explicit workload/serving assumptions, complete all-attempt usage, and separation of post-switch traffic. All final enrolled units/failures remain. Exact wall time and exposure counts may be observed; causal savings against another monitoring policy require a different identifying design. Collector reports host capacity and measured pilot resources before fixing the main horizon; no unbounded sweep or paid capacity is authorized.
2. **Independent adapter validation and CPU operating characteristics — [issue 12](https://github.com/ykzeng-yale/ICLR-WinRatioAgentEval/issues/12).** Claimable separately, preferably by an independent worker. Required deterministic fixtures precede trial execution. A fixed eight-cell known-truth simulation panel, explicit finite repetition/horizon caps, common-draw comparator definitions and Monte Carlo uncertainty are specified in the issue. This verifies the new implementation and its stated errors; it does not repeat every prior study or establish production effectiveness. Deliver a single command, protocol/config/seeds/code hashes, all planned tables, resource report and reviewable PR.

The fixed proposed CPU grid is a planning specification, not an executed result. The owner may reduce it for measured resource limits only before outcomes and must document that freeze. Wider models, hardware replication, full tie/Pareto/grader grids and production users are deferred: they need a specific new claim and a separate resource/identification plan. No study is complete merely because files are uploaded. Root separately checks delivered, independently validated and integrated states.

Execution restrictions: no new commercial/proprietary agents, user simulators, judges or fallbacks; no paid compute; no model download on the root host with about 17 GiB free. Existing local-model availability on another host must be verified. Original observations, failures, protocol amendments and historical artifacts are immutable. Freeze exact tasks/seeds/configuration and horizon before collecting outcome evidence; a no-decision or unfavorable result counts as a completed experiment if the plan is fulfilled.

Scientific acceptance is effect-independent: an auditable design, every planned record or explicit failure/missingness disposition, reproducible analysis, valid inference for the actual design, and candid limitations. A deployment crossing, a significant difference or a higher readiness percentage is never a collection target.
