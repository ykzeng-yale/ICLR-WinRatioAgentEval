## MUST resolve before integrating stronger claims

1. **Fix PR 8's inference-to-design mismatch.** `experiments/local_stream/protocol.md:43–49,277–281,393` and `results/local_stream/report.md` describe independent pairs/population time-uniform bounds, but tasks are a random permutation of a fixed roster without replacement. Disjointness and fresh calls do not establish constant conditional means; exchangeability alone does not imply the pointwise conditional null used by the betting process. Use an appropriate finite-population/randomization analysis, a correctly targeted running-conditional-mean analysis under justified assumptions, or label these bounds/crossings as conditional-method illustrations rather than established population guarantees. This is an analysis repair; existing episodes can be retained. The empirical reviewer independently identified the same issue.

2. **Keep actual execution, estimands, and decisions distinct.** The coding E1/E2 estimates compare different targets, different observation counts and different interval constructions. Their observed gap and tier decomposition are descriptive; they do not by themselves establish a population gap or a pairing-efficiency gain. Airline `protocol.md:74–111,136–160,391–405` adds repeated tasks/shared trial seeds and batch execution to the same inference problem. Its all-four within-task primary comparison also includes same-seed pairs: do not silently label it the manuscript's independent-run off-diagonal target. Do not import “B_harmful/retain A” as a symmetric guarded approval of A.

3. **Integrate PR 7 only with its audited qualifications.** Preserve equal 2N execution accounting, actual look schedules, same-look convention and finite-sample versus asymptotic validity classes. A Wilson interval containing 0.05 is not proof that a method holds its level. Report the rare-compliance gate error separately from simultaneous guarded error; neither may replace the other. The theory reviewer finds no mandatory new CPU experiment for reasonable integration, but requires several prose corrections and either an archived diagnostic or qualified language for the variance-collapse explanation.

4. **Close the delivery and protocol ledger honestly.** Audit/manifests and claim-to-output links must precede declaring PR 8/PR 7 integrated. The airline run remains owned, incomplete evidence until real final artifacts are delivered; do not duplicate it. The original `experiments/protocol.md` is broader than the executed manuscript. Mark unexecuted scenarios and reduced Monte Carlo counts as deferred/amended, rather than claiming every original required panel was run. Current explicitly bounded results need not be rerun merely to match a blanket count.

These are mandatory integration/claim conditions, not a demand for a new production trial or a favorable result.

## HIGH VALUE for the online-evaluation thesis

- **Complete the existing airline job under its frozen stopping/resource rules.** It would extend fresh evidence from executable coding tasks to interactive tools and an open-weight user simulator. Retain every enrolled unit and infrastructure failure, audit simulator/endpoint fidelity, and report dependence and model/hardware scope. With only 49 constructed pairs, abstention may be the scientifically correct result; do not adjust the margin or hierarchy to force a crossing. Completion is high value, not a prerequisite for the existing release's limited claims.
- **Add one focused CPU-only drift/weak-null panel if strengthening the empirical monitoring claim.** The original plan calls for common context drift, treatment-by-time drift and unequal-law mean-win nulls. The shipped adaptive-orientation zero-target stress test does not span all these mechanisms. A prespecified panel should distinguish constant conditional nulls from running-average nulls, state each false-deployment event, preserve shared draws and report Monte Carlo intervals. This tests the stationary/drifting distinction without more model calls. No particular numerical excess must be engineered or promised.
- **For an operational latency claim, collect actual concurrent prefix evidence.** Current asynchronous gains are synthetic and the archived-prefix certificate study uses an ordinal schedule. The coding run is sequential; the planned airline run is batched and sequential. A future open-model concurrent run with actual reveal timestamps, nonanticipating certificates, fixed endpoint horizons and the matched completed-prefix comparator could address this gap. Specify the target and shared-resource assumptions first. Until then, retain the present “feasibility, not operational latency savings” limitation.
- **If practical selection advantage becomes a headline, study a prespecified informative comparison.** Neither identical observed coding success with a large resource penalty nor the original equal-performance synthetic cases establish superiority over component-based decisions. Choose and justify the preference and workload before outcomes, compare the existing guarded-efficiency/incumbent objective at stated error control, and retain abstention or agreement. This is a competitiveness study, not a requirement that the hierarchical rule win.

## OPTIONAL extensions and original-plan coverage limits

The original protocol's exact 0/50/90% tie grid, finite-mean Pareto-cost/controlled-timeout family, and full 0/1/5% true-label contamination grid are not demonstrated by the current lognormal scenarios, two tie-heavy extensions and four grader laws. These would broaden robustness evidence; the existing manuscript already limits those claims. Likewise, the original 5,000-repetition power target exceeds the delivered 2,000-repetition principal studies: document the deviation and use the reported Monte Carlo precision; extra repetitions are warranted only for a specific unresolved comparison.

More open-model sizes, hardware, fresh task seeds, application-elicited margins, a finite-sample all-pairs comparator, and externally observed production workloads are extensions. A production-user trial would be necessary for a production-effectiveness claim, which this submission does not make. No arbitrary experiment count or positive model result is a completion criterion.
